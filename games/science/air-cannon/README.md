# 空氣炮小科學家 · Air Cannon Lab

FunLearning 科學分類的二年級空氣炮公平測試遊戲。

## 設計

- **Canvas 2D + 自訂空氣脈衝模型**：不引入 Three.js 或物理引擎，讓空氣圈、蠟燭與變因的因果關係保持透明。
- 五關：
  1. 密封 vs 未密封
  2. 小膠樽 vs 大膠樽
  3. 細／剛剛好／大出氣口
  4. 輕拉 vs 用力拉
  5. 側風挑戰：調整瞄準
- 每關先預測，再做所有公平測試，最後從實驗紀錄選結論。
- 每關 100 分：預測 20 + 實驗 20 + 結論 40 + 表現 20；平台 `maxScore` 500。

## 空氣脈衝模型

空氣圈有半徑、中心高度與強度；只有當它覆蓋蠟燭而且力量足夠時，蠟燭才會熄滅。

- 膠樽大小改變空氣量與力量。
- 出氣口大小交換「集中」與「分散」。
- 拉力改變空氣速度。
- 密封與否改變漏氣損失。
- 側風移動空氣圈中心，玩家要用瞄準修正。

這不是流體力學模擬，而是為二年級設計的因果模型；數值與動畫是為了讓「改變一個條件」清楚可見。
