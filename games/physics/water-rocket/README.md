# 水火箭 · 抛体实验室

FunLearning 物理分类的 3D 抛体／水火箭学习游戏。

## 技术栈

- **Three.js r170**：本地 `vendor/three.module.js`，负责 3D 场景、火箭、目标、轨迹与镜头。
- **自订 fixed-step 物理**：`src/physics.js`，不依赖 Rapier / Cannon / Matter。
- **HTML/CSS UI**：参数、预测、HUD、结果与轨迹图。
- **平台计分**：完成五关共 500 分，透过 `game-score` postMessage 回报。

## 物理模型

- **理想抛体**：固定初速与角度，忽略阻力，使用解析解验证 `R = v₀²sin(2θ)/g`。
- **水火箭**：
  - 压缩空气把水从喷嘴推出；
  - 水的动量变化产生推力；
  - 水排空后进入滑翔段；
  - 考虑重力、空气阻力与风；
  - 以 1/240 s 固定步长积分。

模型刻意保持可解释，不模拟液体晃动、火箭翻滚或复杂刚体碰撞。若日后要加入落架、翻滚或地形碰撞，可局部接入 Rapier，但不应该让它接管飞行主模型。

## 五关

1. 45° 最大射程
2. 互补角
3. 高抛／低抛与最高点
4. 水量最佳比例
5. 侧风修正

每关：命中精度 60 + 预测 20 + 效率 20，共 100 分。
