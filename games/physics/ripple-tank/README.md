# 水波槽實驗室 · Ripple Tank Lab

手機優先的二維水波槽模擬器，覆蓋 3B05「波的現象和駐波」的反射、折射、衍射與雙源干涉。

## 兩種呈現

- **真實水波**：以 2D finite-difference 波方程計算高度場，再用梯度、法線、鏡面高光與焦散效果繪製水面。
- **波陣面／射線**：顯示等相位波陣面、入射／反射／折射射線、法線、節線與量度工具。波陣面間距為一個波長 λ。

## 五個情境

1. 自由水波：平面波／圓形波
2. 反射：可調障礙物角度
3. 折射：可調界面傾角與淺水區波速
4. 衍射：可調狹縫寬度
5. 雙源干涉：可調波源距離，顯示節線與程差

## 量度

- 在畫面上點兩點量度距離；可用來核對 λ。
- 干涉模式點一點，顯示 `Δ = |S₁P − S₂P|`、`Δ/λ` 與相長／相消判斷。
- 反射與折射的自動角度讀數。

## 物理模型

```text
u_tt = c(x,y)² (u_xx + u_yy) − damping · u_t
v = f λ
sin i / sin r = v₁ / v₂
```

- 深水波速 12 cm/s；淺水波速可調。
- 頻率不變；淺水區的波長變短。
- 硬邊界產生反射；狹縫產生衍射；兩個同相源產生干涉。
- 波陣面使用解析幾何繪製，確保相鄰同相位波陣面間距準確等於 λ。
