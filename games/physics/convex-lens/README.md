# 凸透鏡成像實驗室 · Convex Lens Lab

FunLearning 物理分類的高中凸透鏡成像模擬器。

## 光學模型

使用薄透鏡符號約定：

```text
f > 0
u > 0（物體在左）
v > 0 實像在右；v < 0 虛像在左
m = −v/u
1/f = 1/u + 1/v
```

- `u > 2f`：倒立、縮小、實像。
- `u = 2f`：倒立、等大、實像。
- `f < u < 2f`：倒立、放大、實像。
- `u = f`：折射光線平行，像在無限遠。
- `u < f`：正立、放大、虛像。

## 功能

- 可拖動的物體、焦距／物距／物高滑桿。
- 三條主光線：平行主光線、中心光線、焦點光線。
- 可選光線扇、光屏、標註。
- 即時顯示 `v`、`m`、`h′`、像的性質與薄透鏡公式。
- 五個任務涵蓋五種成像規律，全部答對 500 分。

## 技術

- Canvas 2D 自訂幾何光學繪圖，沒有物理引擎或 3D 依賴。
- 所有像的位置由 `solveLens()` 計算，光線與數字共用同一個結果。
- 平台 iframe 用 classic `src/boot.js` 再 dynamic import `main.js`，避開某些嵌入式 iframe 的 module script 競態。
